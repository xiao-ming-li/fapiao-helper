
# 发票报销助手

基于开源项目二次开发的本地发票处理工具，主要用于批量处理 **纯文字版 PDF 电子发票**，自动提取关键字段，一键生成 Excel 报销表和合并 PDF 附件。

## 功能特点

- **批量处理 PDF 电子发票**（核心功能，识别最准确）
- 自动提取：发票号码、开票日期、销售方、购买方、发票金额、税额、价税合计
- 生成 Excel 报销表（含“报销单”和“发票清单”两个工作表）
- 自动合并本批发票为一个 PDF 附件
- 支持飞机票行程单（金额=总金额，税额为 0）
- 自动识别重复发票

## 使用方法

1. 准备一个**纯英文路径**的文件夹，例如 `C:\fapiao`
2. 把待处理的 **PDF 发票**放入该文件夹
3. 双击 `发票助手\gui_app.exe`
4. 点击“选择目录”，选中发票文件夹
5. 点击“开始处理”，稍等几秒即可
6. 打开生成的 `报销表_xxx.xlsx` 即可查看结果


## 注意事项

- 本工具**只支持纯文字版 PDF 电子发票**，识别效果最好，金额和税额最准确。
- **图片、扫描件、拍照截图无法处理**，因为程序没有配置云端 OCR 接口，识别不出文字，金额和税额会显示为 0。
- 发票文件夹路径必须**全英文**，不能有中文或空格。
- 发票文件夹里只放发票文件，不要放其他无关文件。
